ARCHITECTURE

Core Variables & Message Flowchart

Understand roles, content structures, and how variables move data to GROQ!

instructions Variable

A string variable that holds your system prompt rules. It gets sent under "role": "system" to set the AI's identity.

conversation List

A list storing dictionaries. Each dictionary contains two keys: "role" (who spoke) and "content" (the text message).

Role: "user"

Represents messages typed by the student (e.g. {"role": "user", "content": question}).

Role: "assistant"

Represents responses generated by GROQ (e.g. {"role": "assistant", "content": answer}).

Data Flow
1. System & History messages = [{"role": "system", "content": instructions}] + conversation
➔
2. Sent to GROQ client.chat.completions.create(...)
➔
3. Extract Response response.choices[0].message.content

Step 6: Chat Loop, Commands & GROQ Request

# GROQ Request Code Snippet:
messages = [{"role": "system", "content": instructions}]
messages.extend(conversation)

response = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=messages
)

Step 7: Extract, Store & Start App!

# Extract Answer & Start App Code:
answer = response.choices[0].message.content
conversation.append({"role": "assistant", "content": answer})
